# Customer-Segmentation-Project

This repository contains a **Customer Segmentation & Analytics Dashboard** built using Microsoft Excel. The project categorizes business customers into structured behavioral groups to enable data-driven targeted insights.

## Key Features
* **Clustering Analysis:** Used dynamic logical algorithms to segment users into VIP (High Spenders), Regular, and Budget groups based on spending behaviors.
* **Demographic Breakdown:** Tracked and structured data metrics regarding client Age, Annual Income, and Gender distribution.
* **KPI Metrics:** Computed operational summaries like total audience count and the mean average age of the demographic base.

## Technology Applied
* Microsoft Excel (Dynamic Logical Arrays, Advanced Cell Formatting, Data Sorting)
